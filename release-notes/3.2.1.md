## Check for Updates works

In every build since it was added, **Check for Updates…** reported "Couldn't
reach the update feed" with `CERTIFICATE_VERIFY_FAILED`. The feed was fine; the
app had nothing to check its certificate against.

HTTPS needs a bundle of trusted certificate authorities. A packaged app's
OpenSSL looks for that file at a path baked in from the machine it was *built*
on — a Python installation that does not exist on yours — so every secure
request failed. It never showed during development, because Apple's own Python
trusts the macOS keychain regardless of any file.

The app now carries its own certificate bundle and uses it for the update
check. Verification is still fully on; nothing about the check was loosened.

One consequence worth knowing: because the check was broken in 3.0.0 through
3.2.0, those versions cannot tell you about this one. If you are on any of
them, download 3.2.1 once from the SiRPS page — after that, updates will find
you.
