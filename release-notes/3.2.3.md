## One project backup, not one per save

A two-hour recording left 54 project backup files in its folder — one
`.rpp-bak` for every save, each with its own timestamp.

That comes from three of REAPER's own defaults working together: auto-save
every minute, auto-save any time (including while recording), and "timestamp
backup", which makes each backup a new file instead of replacing the last one.

A new Preferences option, on by default, keeps **one rolling backup**: a single
`.rpp-bak` of the previous save, overwritten each time. Auto-save is left
exactly as it was — still every minute, still during recording — so a crash
mid-show is covered just as before. Only the pile of files goes.

Untick it to go back to a timestamped file on every save.
